# UI Kit Help Desk

## Descripción

Este proyecto corresponde a la Actividad #5 de la Unidad III: Estilo de un documento web y diseño adaptable.

Se desarrolló una librería de componentes UI reutilizables para un sistema de gestión de incidentes Help Desk, utilizando HTML5 y CSS3 puro.

## Componentes incluidos

- Paleta de colores corporativa
- Botones primario, secundario y de peligro
- Campos de texto
- Listas desplegables
- Tarjetas de tickets
- Badges de prioridad
- Alertas del sistema

## Tecnologías utilizadas

- HTML5
- CSS3
- Variables CSS
- Flexbox
- CSS Grid
- Media Queries
- Estados hover, focus y active
